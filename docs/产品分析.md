# “缓一缓”职场情绪整理站｜产品分析

## 1. 产品定位

“缓一缓”是一款面向上班人士的轻量 AI 对话工具，服务于一次具体职场事件后的情绪表达与自我整理。它不提供心理诊断，也不替代心理咨询；它帮助用户把混杂在一起的事实、情绪、担忧与行动分开。

一句话价值主张：下班前用五分钟，把今天的情绪从脑海里放到桌面上。

## 2. 目标用户

- 22—35 岁、工作 0—8 年的城市职场人；
- 高频经历临时加活、汇报焦虑、跨部门摩擦、被否定或职业倦怠；
- 有表达与整理需求，但不一定愿意向同事或朋友倾诉；
- 希望被理解，同时反感空洞安慰和过早说教。

## 3. 核心问题

职场压力往往同时包含三层内容：实际发生的工作事件、用户对事件的情绪反应，以及对评价、关系或未来结果的担忧。普通聊天产品容易立即给建议，造成“没有听懂就开始指导”的体验。

本产品采用五步对话：

1. 聚焦一件具体事件；
2. 命名情绪并标记强度；
3. 识别情绪背后的担忧；
4. 澄清当下真实需要；
5. 形成十分钟内可以开始的最小行动。

## 4. MVP范围

包含：三种对话入口、五步结构化脚本、快捷表达、自由输入、复盘卡、风险表达分流。

暂不包含：账号体系、长期记忆、情绪诊断、企业管理后台、同事关系评价、自动联系第三方。

## 5. 产品原则

- 先理解，再建议；
- 一次只问一个问题；
- 用户有权跳过、修正或停止；
- 不替用户判断同事与领导的动机；
- 不鼓励冲动离职、报复或对抗；
- 出现高风险表达时，安全优先于完成对话。

## 6. 成功指标

- 对话完成率；
- 用户对“被理解程度”的 1—5 分评分；
- 用户认为复盘卡“准确”的比例；
- 最小行动的接受率；
- 平均追问轮次与中途退出点；
- 高风险表达正确分流率。
