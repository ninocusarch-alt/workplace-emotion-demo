# DeepSeek 长期记忆版实现计划

1. 将 Sites D1 绑定设为 `DB`，建立匿名用户、会话、消息和记忆四张表及实际查询所需索引。
2. 建立匿名 Cookie、所有权校验、会话读写、级联删除和频率限制服务。
3. 封装 DeepSeek Chat Completions，使用结构化 JSON 回复、超时和一次重试。
4. 建立职场情绪对话提示、安全分流、复盘卡生成和长期记忆提炼。
5. 新增会话、聊天、历史、记忆同步和清空数据 API。
6. 将前端替换为真实 API 对话，加入历史侧栏、恢复会话、保存状态、错误重试和删除入口。
7. 更新 README、环境变量示例和自动测试，生成并检查 D1 迁移，完成生产构建。
