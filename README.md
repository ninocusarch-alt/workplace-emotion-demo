# 缓一缓｜职场情绪整理站

面向上班人士的中文 AI 职场情绪整理应用。产品通过“选择期待—聚焦事件—识别情绪—发现担忧—澄清需要—最小行动”帮助用户整理一次具体的职场压力事件，并在后续对话中谨慎使用长期记忆。

## 产品场景

- 临时加活与优先级冲突；
- 汇报、述职与绩效焦虑；
- 跨部门协作和同事沟通受挫；
- 工作成果被否定或努力未被看见；
- 工作倦怠与下班后反复内耗。

## 核心功能

- “我想先说说 / 帮我理一理 / 想想怎么办”三种开场模式；
- DeepSeek 生成的五步结构化中文对话；
- 匿名保存历史会话，同一浏览器可继续使用；
- 从对话中提炼压力来源、目标、偏好、有效应对方式与待解决事项；
- 新对话按相关性参考长期记忆，不把全部历史无限塞入上下文；
- AI 自动生成职场情绪复盘卡；
- 高风险表达优先进入安全分流；
- 删除单次对话或清空全部历史与记忆；
- 打印或保存复盘卡。

## 技术方案

- 前端与服务端：vinext / React，运行于 Cloudflare Worker 兼容环境；
- 模型：DeepSeek Chat Completions，默认 `deepseek-v4-flash` 非思考模式；
- 数据库：Cloudflare D1（SQLite）；
- 匿名身份：浏览器保存 HttpOnly Cookie，数据库只保存令牌哈希；
- 长期记忆：结构化提炼、去重、最多保留 30 条，无需向量数据库。

## 本地运行

复制 `.env.example` 为 `.env.local`，填入自己的 DeepSeek API Key。密钥只能保存在本地环境或托管平台的服务端变量中，不要提交到 GitHub。

```powershell
npm install
npm run dev
```

打开终端显示的本地地址即可体验。

生成数据库迁移并验证生产构建：

```powershell
npm run db:generate
npm test
```

## 数据与隐私

本项目不需要账号。浏览器通过匿名标识找回 D1 中的历史记录，因此清除 Cookie 后将无法再关联原有数据。界面提供单次删除和全部清空能力。请勿输入真实姓名、公司名称、联系方式、商业机密或其他敏感信息。

## 产品边界

本产品用于日常情绪表达和自我梳理，不提供心理诊断，不替代心理咨询或紧急援助，不应用于企业监控、员工评价或自动化人事决策。
