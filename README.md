# 缓一缓｜职场情绪整理站

面向上班人士的五分钟职场情绪整理 Demo。产品通过“选择期待—聚焦事件—识别情绪—发现担忧—澄清需要—最小行动”帮助用户整理一次具体的职场压力事件。

## 产品场景

- 临时加活与优先级冲突；
- 汇报、述职与绩效焦虑；
- 跨部门协作和同事沟通受挫；
- 工作成果被否定或努力未被看见；
- 工作倦怠与下班后反复内耗。

## Demo功能

- “我想先说说 / 帮我理一理 / 想想怎么办”三种开场模式；
- 五步结构化中文对话；
- 职场情境快捷表达与自由输入；
- 自动生成职场情绪复盘卡；
- 高风险表达的安全分流示例；
- 打印或保存复盘卡。

当前版本采用本地规则演示完整产品流程，不发送或长期保存用户输入。正式接入大模型时，应继续保留对话边界、安全分流、用户删除权和人工评测。

## 本地运行

```powershell
npm install
npm run dev
```

打开终端显示的本地地址即可体验。

## 产品边界

本产品用于日常情绪表达和自我梳理，不提供心理诊断，不替代心理咨询或紧急援助，不应用于企业监控、员工评价或自动化人事决策。
